Sistema integral para gestión de bandas y facciones ilegales. Incluye menús criminales interactivos, control de venta de drogas, registro de actos semanales y sincronización completa con bases de datos MySQL y Prisma.

Herramienta de control institucional para fuerzas del orden. Cuenta con control de turnos (duty), fichajes de agentes, expedientes criminales centralizados y reportes activos de oficiales con comandos de barra avanzada.
